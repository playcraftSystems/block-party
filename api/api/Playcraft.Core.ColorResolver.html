Class ColorResolver

Resolves the colour of a mesh or layer in a part's 3D model: name → longest matching material prefix → its colour setting and material → the colour name from the part's override, else the project's deviation, else the scheme, else the prefix's default → the material's palette → the value. Never throws on data: an unknown name, or a colour no palette has, resolves to NeutralGray and says why.
