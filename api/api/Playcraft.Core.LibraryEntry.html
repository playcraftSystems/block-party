AllowedAttachments

The catalog Categories this part auto-carries as dependent attachments — the file's comma-joined <AllowedAttachments> text, split and trimmed. Directional and OWNER-side: a slide names its "Single Slide SitDown Wall"/"…Hood" categories, a climber its half/transition walls; the dependent itself only carries the matching Category. Empty when the part carries no dependents. This is the declaration behind the dependent auto-carry rule (see DependencyCatalog).
