Class CatalogFilter

Catalog compatibility rules, straight from the catalog file's own data: which parts fit a clicked host (MatesWith family + system type + the age envelopes' deck-height range) and which suit an age band.

FitsHost(LibraryEntry, CatalogFit)

Whether a catalog part fits the clicked host: the part must declare the host's family in its MatesWith list, the systems must be compatible, and (when the host height is known) at least one age range the part is appropriate for must cover that height. A 0/0 range means any height; a part with no age data at all is not height-checked.

ResolveFit(ComponentLibrary, string?, string?, double?)

Builds the fit context for a placed component: its catalog entry when the part number is known, else a generic system-agnostic deck for tagged decks the catalog doesn't list (command-drawn spike decks). Returns null when there is nothing sensible to filter by.
