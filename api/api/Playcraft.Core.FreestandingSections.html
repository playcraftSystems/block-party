Class FreestandingSections

Quote sections for components a designer left outside every group. The bucket names come from the component library's own family vocabulary, which the bundled price list repeats verbatim, so they resolve with no vault and no network.

Remarks

This is the path that makes loose site furnishings work without ceremony: a designer drops in benches and trash cans and never groups them, and they still reach the quote under a heading a customer understands.
