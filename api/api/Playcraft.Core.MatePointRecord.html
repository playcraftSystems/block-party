Class MatePointRecord

One mate point of a catalog part from the canonical mate table (data/mates/mate-points.csv, generated by build/build-mate-table.ps1). Geometry and type attributes both come from the library component XAML's MatePoints block — verified 1:1 against the engineering DWGs' mate marker blocks on every part the earlier DWG-join table covered.
