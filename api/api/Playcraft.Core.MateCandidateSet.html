Class MateCandidateSet

The shared candidate-set primitive behind every mate-point consumer — the click path builds one per click, the F-032 jig builds one per jig start and queries it per cursor sample, and the F-033 osnap overrule shares WorldMatePoints(IReadOnlyList<MatePointRecord>, Transform2) for its per-entity variant. Precomputes every component's world-space mate points and a PointGrid over the occupancy positions; ForChild(MatePointRecord) adds a per-child grid over the compatible host points. The grids only narrow candidates: every returned match re-runs the exact per-host predicates of the original scan (CompatiblePoints(IReadOnlyList<MatePointRecord>, string, string, string, string, string, MateRules) plus Choose(IReadOnlyList<SnapPoint>, IReadOnlyList<Pt>, Pt, double, double)'s closed-interval distance rules), so answers are bit-identical to FindSnapReference(MatePointRecord, Pt, double, double), the retained O(n²) oracle — the differential tests hold this to account.

SameLevelTolerance

How far apart in elevation two components may sit and still count as the same level, inches. Not a chosen number: it is the largest step the filler catalog spans (FillerData.xml offers 6", 12", 18" and 24" and nothing more), so it is the domain's own answer to "do these two decks MEET, or are they separate storeys" — a filler closes the gap where they meet, and there is no filler beyond this.

Declaration
public const double SameLevelTolerance = 24
Field Value
Type Description
double
Remarks

Measured against the reference designs: deck pairs that coincide in plan separate cleanly into gaps of 6–30" (decks meeting at a seam, 42 pairs) and 54–144" (decks on different levels, 66 pairs), with no pair anywhere in between. This threshold sits inside that empty band, so every real seam keeps occupying and every real tower stops.

FindSnapReference(MatePointRecord, Pt, double, double)

The retained specification: a verbatim port of the original per-host scan (MateSnap.TrySnap) — for each non-post host with mate data, filter its points through CompatiblePoints(IReadOnlyList<MatePointRecord>, string, string, string, string, string, MateRules), harvest every other component's occupancy positions, run Choose(IReadOnlyList<SnapPoint>, IReadOnlyList<Pt>, Pt, double, double), and keep the strictly nearest snapped point across hosts. O(n² · mates) per call; kept public and unoptimized as the oracle the fast path must match bit-for-bit.

WorldMatePoints(IReadOnlyList<MatePointRecord>, Transform2)

Transforms a part's mate table to world-space snap points — position by the full transform, mate vector by the linear part renormalized. This is the single shared table-to-world conversion (the F-033 overrule calls it per entity), so no two consumers can disagree about where a mate point is.
