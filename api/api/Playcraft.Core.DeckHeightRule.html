Class DeckHeightRule

The deck-height editing rule shared by every entry point that accepts a height (PBHEIGHT, PBSTAMP's prompt, the KCD importer's warning): heights live on the catalog's 6" grid, inside the 6" to 156" editing range, under the 108" cap for surface-mount decks, and inside the part's own age envelopes. A height that breaks a rule is refused with a named reason, never silently rewritten. The envelope semantic is FitsHostHeight(IReadOnlyList<AgeFit>, double?)'s: any appropriate band covers the height, 0/0 means any, and missing data never blocks, so the editing rule and the catalog fit filter can never disagree.

Remarks

No deck in the component library declares a surface-mount label at the part level, so this returns false for every catalog deck today and SurfaceMountCapInches is a rule waiting on its input. The cap is implemented but not yet enforced anywhere.

OnGrid(double)

Whether a height sits on the catalog's 6" grid. Purely modular — range is Check(double, IReadOnlyList<AgeFit>, bool)'s concern, so 0 is "on grid" here and the KCD importer's warning stays quiet about height-less components.
