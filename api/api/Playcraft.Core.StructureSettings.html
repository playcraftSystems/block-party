Class StructureSettings

What one structure (a designer's named group, or the drawing default every loose part and every new structure reads) declares about itself: its age range, rail system, mounting, post material, and whether it takes IPEMA-certified parts only. Every field may be unset (null, or false for the IPEMA flag); each rule that reads a field says what it does when it is unset. The product type is not here: it is derived from the structure's parts (OfParts(IEnumerable<(string Type, string? Family)>)), and ForProductType(string?) applies what it forces.

FromKcd(string?, string?, string?, string?)

The settings a design file's StructureProperties declares, normalised the way the legacy tool normalises them on load: every value trimmed and a blank one unset; the age range and system in their canonical casing, the legacy system names ROUND5 and ROUND305 read as R5 and R35; the mounting type with a trailing underscore stripped and then read by its first letter (I is in-ground, S is surface mount, anything else falls back to in-ground). A value outside the known lists is kept as written, trimmed. The IPEMA flag has no place in the file, so it is false.
