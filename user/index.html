User Guide

Every feature, and why it is there#

59 commands. Type one at the AutoCAD command line.

Each entry below says why the feature was built, then how to use it. The sections run in the order a designer meets them: set the library up, place parts, build the structure, look at it, count it, send it out, check it.

New here? Read the Quick Start first. It installs the plugin and walks one small layout end to end.

Setup

PBSETUP

Sets where the component library is and, optionally, your pricing token.

It opens by itself the first time if no library is set. Browse to the folder that holds the family folders (Access Components, Decks, and so on). The window shows what it found, such as 233 families, 6516 components; 0 families means the folder is wrong. Paste a pricing token if you have one and press Test connection, or leave it blank. Run PBSETUP again whenever either answer changes.

Added in version 0.8.0

PBVAULT

Sets the component library folder from the command line and reports what the plugin can see there.

Type the path. It prints how many families and components it found and which data files it found. The choice is saved per user and shown every time the plugin loads. Parts already placed keep their look; new placements read the new library. An environment-variable override wins over the saved path, and the command says when it does.

Added in version 0.7.0

PBMCP

Turns on the connection an AI assistant (Claude Desktop) uses to read this drawing.

Run it once per AutoCAD session. The assistant can then ask for the priced bill of materials, the same totals PBPRICE prints. It only reads the drawing. If a command is running when the assistant asks, it is told to wait and nothing changes.

Added in version 0.18.0

PBMCPRUN

Helper: runs the assistant's waiting requests. The plugin types it for you after PBMCP.

You do not need to type it. Each change the assistant makes runs inside it, so one UNDO takes that change back.

Added in version 0.19.0

Place parts

PBCATALOG

Opens the parts panel, where you search, filter and place components.

Search by name or part number. Dashes and case do not matter, so S-1101-R5 and s1101r5 find the same deck. Quote a phrase to keep it together, and put a minus in front of a word to leave it out. Filter by family or price, and click a column header to sort. Double-click a part to place it. The settings row at the top (Age, System, Mounting, Posts, Deck, Show, IPEMA only, Canada) sets what you place next and hides parts that do not fit; tick Show hidden parts to see them with the reason. Placed parts keep the settings they were placed with. To change placed parts, select them and click Apply the row to selection. Clear all resets the row, the search and the filters. One U takes back each click.

Added in version 0.4.0

PBFIT

Shows only the catalog parts that fit a part you have already placed.

Select a placed part, or run it and click one. The catalog opens on it and lists only the parts that fit one of its free connection points and are rated for its height at its age range. The line above the list counts what was left out and why: not rated for that height, or it fits only points already taken. The catalog does this by itself on its Fits here tab whenever one part is selected. Double-click a listed part to place it on a free point; the free point list picks which one. With a deck selected, the Over it tab lists the roofs and canopies that go over it, each at the height it would take.

Added in version 0.4.0

PBFITPLACE

Places a part on a free connection point of a part you have already placed, with no questions.

Double-click a part on the catalog's Fits here or Over it tab; that runs it. It places the part through the same snap as a click, on the chosen free point, with its posts and any wall it carries. A deck joins level with the deck it attaches to when it is rated for that height. A roof or canopy goes over the selected deck, centred as a click on the deck's middle puts it, at its worked-out height. The part attached to stays selected. Typed, it asks for the part to attach to, the part number and the point. One U takes it back.

Added in version 0.24.0

PBSTAMP

Places parts with a ghost that follows the cursor and snaps to connection points.

Pick a part and move the cursor. Nearby connection points show green when free and grey when taken. The words at the cursor say what the part will attach to, or why it cannot and where it could. A part about to land unattached turns red. While placing, type Next to attach by the other side, Angle to type an angle, Rotate or Counter to turn one step (30 degrees unless changed), Turn for half a turn, or Free to turn snapping off. Decks ask for their height first. Click inside a placed deck to stack the next storey on it. Click to place as many as you like, and press Enter to finish.

Added in version 0.6.0

PBDROP

Places a part where it was dragged and dropped from the catalog, with no questions.

Drag a part from the catalog palette into the drawing; the drop runs it. It snaps like a click, and every question takes its default: a deck takes the height the catalog offers, a part with a sit-down wall takes the first choice, and a roof on a structure with no age range takes its lowest clearance. One line says what was taken. Change heights later with PBHEIGHT. Typed, it asks for a part number and a point.

Added in version 0.20.0

PBROT15

Turns the selected parts one turn step counter-clockwise: 30 degrees unless you change the step.

Select parts and run it, or click the counter-clockwise turn button on the catalog palette. The step is the TURN STEP box on the catalog, which is AutoCAD's polar angle (POLARANG). Each part turns about its own insertion point; a selection that holds a deck turns as one structure about its first deck. It is AutoCAD's own ROTATE underneath, so one U takes it back and posts and fillers follow as they do for any ROTATE. For any other angle, or to line a part up with a fence, use ROTATE itself.

Added in version 0.16.0

PBROTBACK15

Turns the selected parts one turn step clockwise: 30 degrees unless you change the step.

It works like PBROT15 but turns clockwise. The clockwise turn button on the catalog palette runs it, and one U takes it back.

Added in version 0.16.0

PBATTACH

Places the 24 inch wave slide at the nearest free connection point to your click.

Click near a deck edge. The slide lands on the nearest free connection point within 8 inches. Incompatible pairs are refused and taken points are skipped. Every other slide places from the catalog.

Added in version 0.1.0

PBMATES

Shows every connection point in the drawing, green when free and grey when taken.

Run it to mark the points. Run it again to hide them. The marks are drawn over the drawing and never added to it, so there is nothing to erase, nothing that plots, and no effect on the parts list. They show the drawing as it was when you ran the command. After moving or placing something, run the command twice to refresh.

Added in version 0.12.0

Structure

PBGEN

Checks every post in the drawing and puts it right.

Run it. There are no prompts. Posts already follow every edit, including plain MOVE, COPY and grips, so run it to check them or after an UNDO. Every part brings the posts its library record names, not only decks. Posts closer than an inch are one shared post, sized for the tallest part standing on it, and carry the real whole-foot catalog part number. Posts already in place are kept, wrong lengths are re-sized, missing ones are added and posts nothing stands on are removed. A designer's own cut post is never changed; a disagreement is named instead.

Added in version 0.1.0

PBPOSTHEIGHTS

Shows or hides the ring with each post's height in it.

Tick or clear Post heights on the catalog palette, or type it and answer On or Off; Enter switches. It turns the PostFootings layer on or off, and makes the layer when the drawing has none. Turning that layer on or off in AutoCAD does the same, and the box follows.

Added in version 0.20.0

PBROOFS

Shows or hides roofs, shade canopies and toppers, so the decks under them read.

Tick or clear Roofs on the catalog palette, or type it and answer On or Off; Enter switches. Roofs are drawn dashed on the PB_Roofs layer, with their height label below their centre; this turns that layer on or off. Turning the layer on or off in AutoCAD does the same, and the box follows.

Added in version 0.20.0

PBCOLORFILL

Shows or hides soft colour fills under the parts in plan, in each part's colours.

Tick or clear Colour fills on the catalog palette, or type it and answer On or Off; Enter switches. On fills every part from its 3D model. After that the fills change colour with every colour change, and U takes the colour back with them. The fills sit on the PB_Fill layer, under the part's lines; Off turns that layer off for a black-and-white print. Roofs get no fill.

Added in version 0.25.0

PBZONES

Shows or hides the use zones, so the parts and the selection read.

Type it and answer On or Off; Enter switches. A part's use zones are on layers of their own (UZ_, SLZ_, SWZ_, CZ_). They arrive off, in one faint grey. This turns those layers on or off. AutoCAD's own LAYER works on them too, and the plugin keeps what you set.

Added in version 0.25.0

PBFILL

Adds, swaps or removes the fillers where decks of different heights share posts.

Run it. There are no prompts. Each height step gets the filler its edge length calls for. Run it again after decks move, change height, or go away: fillers are kept, swapped, or removed to match. One you swapped for an equivalent style is kept. Imported decks that arrive without post data keep their fillers, and the report says how many it could not verify.

Added in version 0.5.0

PBHEIGHT

Changes the height of a deck or a roof that is already placed.

Click a deck, or press Enter for every deck, then give the new height. Decks selected before you run it are the ones it changes, a tower's storeys included; the catalog's Selected section runs it this way from its height list. A roof, shade canopy or topper over a changed deck moves with it and keeps a raise. To raise a roof itself, type Roof, click the roof and give the height: roofs go up in 12 inch steps from the lowest height their decks and age range give. Heights step by 6 inches, run from 6 to 156, and must sit inside that deck's rating at its structure's age range; a structure with no age range set accepts any of the deck's ratings. A refused height says why, names the range the deck is rated for, and leaves the deck where it was. The tag and the visible label change together. The deck's posts are re-sized in the same edit, so one UNDO takes back both, and step fillers swap because PBFILL runs itself afterwards. Attached parts keep their own height, so re-place them if the new height changes what fits. The edit survives export back to the design file.

Added in version 0.11.0

PBHEIGHTUP

Raises the selected decks one 6 inch step, or the selected roof one 12 inch step.

Select decks or a roof, shade canopy or topper, then run it. There are no prompts. It is PBHEIGHT underneath: a step past the part's rating is refused with PBHEIGHT's message and nothing moves, and roofs, posts and fillers follow. Several decks move together or not at all. One U takes it back.

Added in version 0.25.0

PBHEIGHTDOWN

Lowers the selected decks one 6 inch step, or the selected roof one 12 inch step.

Select decks or a roof, shade canopy or topper, then run it. There are no prompts. It works as PBHEIGHTUP, downwards. A roof cannot go below the lowest height its decks give it.

Added in version 0.25.0

PBPOSTUP

Makes the selected posts one foot longer, and PBGEN keeps them that way.

Select posts, or a deck for all its posts, then run it. The length is recorded on the post, so PBGEN and every later edit keep it and name it in their report instead of resetting it. It stops at 29 ft. PBPOSTRULE puts a post back on the rule.

Added in version 0.25.0

PBPOSTDOWN

Makes the selected posts one foot shorter, and PBGEN keeps them that way.

Select posts, or a deck for all its posts, then run it. It is refused below the shortest stock post (4 ft in the ground, 1 ft surface mount) and where the post would end below its deck; PBPOSTCUT cuts a post to its deck. PBPOSTRULE puts a post back on the rule.

Added in version 0.25.0

PBPOSTCUT

Cuts the selected posts to their deck, with a flat cap.

Select posts, or a deck for all its posts, then run it. Each post becomes the library's factory-cut post whose top is its highest deck, such as S-1006-R5F-9-024-063 for a 24 inch deck, with a flat cap in place of the dome. A post that holds a roof is refused. The cut is recorded, so it follows the deck when its height changes and PBGEN keeps it. PBPOSTRULE puts it back on the rule.

Added in version 0.25.0

PBPOSTCAP

Swaps the selected posts' dome caps for flat caps, and back.

Select posts, or a deck for all its posts, then run it. A dome becomes a flat cap; a flat cap it put on becomes a dome again. The flat cap follows its post's top and is counted on the bill of materials. A post the cap rule gives no cap, or one with a cap you placed by hand, is left and named.

Added in version 0.25.0

PBPOSTRULE

Puts the selected posts back on the post length rule.

Select posts, or a deck for all its posts, then run it. It clears what PBPOSTUP, PBPOSTDOWN, PBPOSTCUT and PBPOSTCAP set, and the posts are sized by the rule again in the same edit.

Added in version 0.25.0

PBSELECT

Selects every part of one kind: decks, roofs and canopies, ground events, elevated events, posts, everything connected to the selected part, or its whole structure.

Run it and answer Decks, Roofs, Ground, Elevated, Posts, Connected or Structure. It leaves an ordinary AutoCAD selection, so MOVE, ERASE and Properties work on it. Ground and Elevated follow the catalog's event type; parts whose event type is optional are left out and counted. Connected starts from the selection and follows mate points, posts, parts hung on posts, walls and roofs. Structure selects every part in the selected part's named group; a part in no group gets everything connected to it. Parts inside a block, or on a locked or frozen layer, are left out and named in one line. The panel's Select list and the card's Select structure link run it.

Added in version 0.25.0

PBNEXT

Lists the next steps for the selected deck, as the panel's checklist shows them.

Select one deck, then run it. Each line is done, now or open: access (a stair, ramp, transfer or climber on the deck or its structure), points used, free points, slides or climbers with no wall, a roof over it, and posts kept as you set them. These are hints for configuring, not a check against any standard; PBAUDIT reports the rules.

Added in version 0.25.0

PBLEVEL

Lists the storey each part stands on, and lets you select a storey or put each storey on its own layer.

Run it for the list: every component and the level it stands on, numbered exactly as an export writes it. Imported designs keep the file's own storey numbers; parts placed here derive theirs from what stands on what, so a tall shade post is still ground-storey furniture. Then answer the prompt. Name a level to select everything on it, so you can move, measure or inspect the storey as one thing. Answer Layers to file each storey onto its own layer, PB_LVL0, PB_LVL1, and so on. Freeze a layer to hide that storey and build on the one above; posts, fillers, counts and exports still see everything on it. Placing, importing and height edits keep the layers current and report what changed storey. Delete the layers to stop. It never edits a component or the design file.

Added in version 0.13.0

PBSTRUCTURE

Sets the age range, system, mounting, post material and IPEMA rule for one structure, or for the drawing default.

A structure is a named group. Run it and click any part of one, or type D for the drawing default. Answer each prompt, or press Enter to keep the value shown: age range, system, mounting (i or s), post material (s or a), and IPEMA-certified parts only (y or n). A swing set or freestanding group is not asked for system, mounting or post material. Parts that no longer fit are listed and selected, and posts and fillers follow in the same command. One U takes it all back.

Added in version 0.16.0

PBREGION

Sets the drawing's region, US or Canada.

Run it and answer US or Canada, or press Enter to keep the region shown. The catalog then hides the parts made only for the other country, any placed parts that are out of region are listed and selected, the audit names them, and the export writes the region into the design file. The region is one setting for the whole drawing, kept in it, and a design file import reads it from the file. One U takes it back.

Added in version 0.16.0

PBSETTINGS

Changes one drawing setting from a typed line, the same as a click in the catalog's settings row.

Type one setting: age=2-5, system=R35, mounting=surface, material=aluminum, ipema=yes, region=Canada, deck=48 or show=structure. An empty value, such as age=, sets it back to not set. apply gives the selected parts the row's settings. use puts the selected parts' settings in the row. use=TOWER puts the TOWER group's settings in the row, and saveto=TOWER gives the group the row's settings. clear sets the whole row back to not set. One U takes each back.

Added in version 0.16.0

PBMIGRATEZ

Lifts parts in older drawings from the ground up to their real heights.

Run it once. Every part whose height label shows where it belongs moves there. Carried attachments follow their owner. Posts stay at grade. Anything without that evidence stays where it stands and is named in the report. It moves parts and never erases them. Run it again on a lifted drawing and it finds nothing to do.

Added in version 0.13.0

3D view

PB3D

Opens a 3D view of the parts in the drawing.

Toggle the palette. Every placed part renders from the library's own 3D drawing, in the drawing's colour scheme: decks at their design height, posts at their part height, slides and climbers at the deck they serve. A part shows as an orange box until its model is ready, then appears. The picture follows every 2D edit. Drag to orbit, right-drag or middle-drag to pan, and use the wheel to zoom. Click a part in 3D to select it in the drawing. Parts with no 3D drawing are shown from their older 3D model and listed on the banner. Parts with no model at all show as orange boxes and are listed by part number.

Added in version 0.10.0

PBSCHEME

Sets the drawing's colour scheme, which the 3D view paints every part with.

Pick a scheme in the Colours list on the catalog palette, or type it and answer with the scheme's name. ? lists the schemes; Enter keeps the current one. The drawing keeps the scheme when saved. PB3D changes colour at once.

Added in version 0.21.0

PBCOLOR

Colours a structure, or single parts, for the 3D view and the design file.

Select a structure (click it with group selection on) or some parts, then pick colours in the Colours section of the catalog palette, or type PBCOLOR and an instruction. ? lists the colours. Posts=Blue sets every colour under a heading; a single colour by its name; Panel=Blue/White sets a face and core together. scheme=Earth gives the structure a scheme. all gives every structure this one's colours. clear=parts and clear=structure take colours off. A whole structure's colours are the structure's; parts picked on their own get colours of their own. The colours are kept in the drawing, come in with PBIMPORTKCD and go out with PBEXPORTKCD. Each change is one U.

Added in version 0.22.0

PBCOLORTABLE

Reads the company colour file again and says which colour table is in use.

Type it after the colour tool saved a new company colour file. There are no prompts. The 3D view and the colour fills show the new colours at once. The 3D view also names the table in use at its top left, under the hint. If the file cannot be read, the colours in use are kept. PBSETUP sets the company colour folder.

Added in version 0.26.0

PBEXPORTGLB

Saves the drawing as one 3D model file (.glb) that Windows' 3D Viewer, phones and Blender open.

Run it and choose where it lands; it suggests the drawing's name. The model is real size, in the 3D view's colours. Each structure is a group named as in the drawing, and each part is named by its part number. Parts in no group sit under "Parts in no group". A part with no 3D model is an orange box, and one line names those parts. It refuses a path inside the component library.

Added in version 0.23.0

Count and price

PBBOM

Prints the parts list, tallied by part number and grouped by structure.

Run it. Every placed component is tallied by part number, with quantities and descriptions, in sections by structure. It works offline: the tallies come from data cached in the drawing. With the parts database configured it also breaks each part into the smaller parts that make it up, as many levels deep as the data goes. A count it cannot settle says so in a note instead of guessing, and a sub-item row it cannot read is counted conservatively and named. Parts printed as Unassigned are in no group yet.

Added in version 0.1.0

PBPRICE

Prices the drawing, with unit and extended MSRP and REP totals.

Run it. It prints unit MSRP, then extended MSRP and REP totals for the layout. With live pricing configured, MSRP is fetched fresh every run in the background, so AutoCAD stays responsive. Without it the built-in price list keeps the numbers coming offline. The table names its price source and flags any part with no price on file rather than hiding it from the total.

Added in version 0.1.0

PBEXPORTBOM

Saves the parts list and prices to an Excel workbook.

Run it and choose where it lands; it suggests the drawing's name with -bom. The workbook has the same structure sections, per-level rows and MSRP and REP totals as PBPRICE, because both read one tally and one set of prices. A name ending .csv saves a CSV instead.

Added in version 0.13.0

PBPANEL

Opens a panel that keeps the parts count and prices current while you work.

Toggle the palette and leave it open. It shows parts, support posts, collars, caps and connection hardware under a heading row per structure with its subtotal, and the MSRP and REP totals, recomputed after every edit. Place, move or erase something and the numbers follow. An OFFLINE badge appears when live prices are out of reach; hover it for the price source. Refresh Prices re-checks on demand.

Added in version 0.2.0

PBSYNC

Refreshes the part names, descriptions and weights stored in the drawing from the web catalog.

Run it. The cached catalog data refreshes in one batched lookup, in the background, so AutoCAD stays responsive. It is the only command that needs the pricing token. Between syncs the drawing keeps working offline.

Added in version 0.1.0

Design files (.kcd)

PBKCDINFO

Shows what is in a design file without bringing any of it into the drawing.

Pick a .kcd file. It prints per-tab counts: components, distinct support posts, attachment points, fillers. It does not touch the drawing.

Added in version 0.3.0

PBIMPORTKCD

Brings one design tab from a .kcd file into the drawing.

Pick a file, then a design tab. Every part lands at its exact position, rotation and height. Without a library, parts land as labeled placeholders. Importing the same tab again replaces the earlier import. Posts arrive as they are in the file and are not re-sized on import. The summary lists anything in the file that does not match what arrived, such as post counts or storey numbers.

Added in version 0.3.0

PBEXPORTKCD

Writes the drawing out to a .kcd design file.

Run it and choose where to save; the default is a new -export copy, so the original is not changed unless you pick it. A drawing that came from a .kcd is written back with your moves, deletions and new parts. A drawing built here is written as a new file. Posts, pairings such as a slide and its wall, each structure's settings and the region are all written. A .json copy is saved alongside.

Added in version 0.3.0

PBDEPS

Checks a design file for slides missing their required sit-down wall and for broken links between parts.

Pick a .kcd file. It reports slides missing a required sit-down, attachments whose parent component is gone, links pointing at components the file no longer holds, and pairs linked in one direction only. Where the design was imported here, it gives drawing positions for what it can locate. It needs the library's catalog data and refuses to run without it. It only reports; it changes nothing.

Added in version 0.6.0

Diagnostics

PBAUDIT

Checks the drawing against the design team's rules and reports what it finds.

Run it. It lists decks 108 inches and up with an open edge, Geo-Wave and traverse heights over the limit, ground panels under a deck too tall for them, the wrong limb climber for a deck, mirrored or scaled parts, parts that do not fit the settings they were placed with, and roofs, shade canopies or toppers not at the height their decks and age range give. Limits are read at each structure's age range. Each finding names the part, gives its position and cites the wiki card the rule comes from. Each rule has a number that never changes (AUD-01 on), then Fix, Decide or Needs information, and who acts. It only reports and never changes the drawing.

Added in version 0.14.0

PBHELLO

Prints which build of the plugin is loaded.

Run it. It prints one line naming the build. Paste that line into anything you report.

Added in version 0.1.0

PBPANELTIME

Times how long the catalog panel takes to follow this drawing.

Not for design work. Select a part and run it. It times the selection card (twice: the first read is cold) and the project header, each against its budget, and prints the panel's own last times.

Added in version 0.25.0

PBNUDGE

Moves a part by a known amount, for automated tests.

Not for design work. Use AutoCAD's own MOVE. This command exists so an automated test can displace a part by a known amount.

Added in version 0.1.0

PBLIBCHECK

Checks that every part drawing in the library reads and that its connection points match the facts kept beside it.

Not for design work. Maintainers run it through build\library-check.ps1, which opens every part drawing read-only and writes a report into the repository. It refuses to write anywhere inside the component library.

Added in version 0.15.0

PBMESHLIB

Makes a 3D model file (.glb) for each library part from its 3D drawing, for the 3D view and exports.

Not for design work. Maintainers run it through build\mesh-library.ps1. It asks for an output folder (Enter for the usual cache folder) and a file of part names (Enter for the whole library), skips parts whose file is already up to date, and writes index.json and failures.txt beside the files. It refuses to write anywhere inside the component library.

Added in version 0.20.0

PB3DSCENE

Writes the 3D view's scene for the drawing to a file, so a maintainer can render it outside AutoCAD.

Not for design work. It asks for the file to write and refuses a path inside the component library.

Added in version 0.20.0

Sheets

PBSHEETS

Makes the drawing's sheets as layouts, with the title block filled in.

Run it. There are no prompts. The sheets are numbered the US National CAD Standard way. It makes G-001 Cover first: the project, issue and revision, the sheet index, the project directory by role, the key figures, a field verification note, and the hero render from renders\<drawing name>\<drawing name>-hero.png beside the drawing (or a frame saying where to put it). Then G-002 Project data: each structure's system, ages, plan size, highest deck, fall height, child capacity and parts, the parts by family, the accessibility counts provided and required per structure, and the site requirements; what the drawing cannot give prints [needs designer input]. Then L-001 General notes: numbered notes and the standards cited. Then L-101 Site plan: the whole site with each structure's use zone dashed and named, slide exit zones hatched, and the surfacing area in sq ft. The play area is a closed polyline you draw on a layer named Play area, or a closed ring of border timbers; with neither, the use zones show as the minimum surfacing area. Zones that overlap or run past the play area are listed. Then L-102 Footing plan: the plan with every footing numbered, the footing types with their sizes and counts, and the footing schedule from footing 1. Then the layout L-103 Component plan on ANSI B (17 x 11): the parts' line work at the largest standard scale that fits, with the title block, scale bar and north arrow. Then L-201 Elevations, one sheet per structure: a front view from the south over a side view from the east, drawn from the parts' 3D models with hidden lines removed, each on a finished grade line, with the highest deck and the overall height dimensioned; parts with no 3D model are named, not drawn. Then L-601 Equipment schedule: one table per structure, numbered as L-103 and counted as PBBOM, with no prices; a long table continues on L-601A. Then L-602 Colour and finish: each colour setting with a swatch, its colour, RAL number, material and the parts' call-out numbers, the colours used, the finish and any part exceptions. Last, L-901 Perspective views: the hero render large and the alternate, aerial and plan renders beside it, from renders\<drawing name>\<drawing name>-<view>.png beside the drawing; a view not rendered yet shows a frame saying where to put it. Run it again after changes: it refreshes its own layouts and never touches yours or anything in model space. Fields the drawing cannot fill print a blank line to fill in by hand.

Added in version 0.26.0

PBSHEETPDF

Plots the sheets PBSHEETS made to one PDF.

Run it and choose where the PDF goes. Every PBSHEETS layout plots into one PDF, one page per sheet, in sheet order, at its own paper size. AutoCAD's PUBLISH works on the same layouts too.

Added in version 0.26.0

PBPAPER

Makes all the paperwork for a saved drawing in one folder.

Save the drawing, then run it. There are no prompts. It runs PBAUDIT, PBEXPORTGLB, PBSHEETS, PBSHEETPDF and PBEXPORTBOM in that order into a folder beside the drawing named <drawing> paperwork, and ends with a list of what was made and what is missing. A step that fails is listed and the next one still runs. It does not save the drawing. The pictures render in Blender in the background: when they are ready the command line says so, and running it again places them.

Added in version 0.26.0

PBPAPERDRAFT

Makes the same paperwork as PBPAPER with draft pictures.

Run it like PBPAPER. The pictures are smaller and rougher. PBPAPER does not reuse draft pictures; it renders its own.

Added in version 0.26.0
